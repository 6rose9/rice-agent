# User Feedback — Rice-Agent

- **How collected:** Chat conversations with 3 participants
- **When:** 27 June 2026

## Raw feedback

1. How will the platform handle posts that are unrelated to the application?
2. How can users know whether a buyer or seller is a genuine rice trader?
3. Will the platform be responsible for payment or lending services?
4. It would be helpful if agents from company could participate to facilitate transactions.
5. It would be useful to have a directory of agricultural supply stores with map directions.
6. Will users be allowed to create posts for agricultural products other than rice?

## Themes (what keeps coming up)

- Users are concerned about trust and authenticity between buyers and sellers.
- Users want a way to verify that members are real, such as phone number verification.
- Users expect trust-building features such as ratings and reviews, along with the ability to report suspicious users or posts to administrators.
- Users want clearer information about the platform's responsibility regarding payments and transactions.
- Users are interested in expanding the platform to include agricultural supply stores and other agriculture-related products.

## Top 3 things to fix

- [ ] Implement phone number verification to improve user trust.
- [ ] Prioritize posts from followed users in the feed.
- [ ] Improve the right sidebar by fetching and displaying useful analytics.
